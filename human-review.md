# Human Review

Я перевірив AI-драфт реальним запуском.

## 1. Create Car

У тесті AI було очікування HTTP "200", але API фактично повернув "201".
Після цього я перевірив наступні запити:

- Get Car → "200"
- Update Car → "200"
- Delete Car → "200"

Отже, машина була створена успішно. FAIL залишив навмисно, щоб зафіксувати невідповідність між очікуваним і фактичним статусом API.

## 2. Cleanup

Перевірив порядок видалення:
"Delete Car" → "Delete User"
Обидва запити завершилися з HTTP "200".
Висновок: створені тестові дані успішно видалилися.

## 3. Negative Case

Перевірив сценарій Signup без обов'язкового "lastName".
API повернув "400", як і очікувалося. Користувач не був створений.
Висновок: Negative Case працює правильно.

## Підсумок

AI-драфт був перевірений реальним запуском. Я знайшов одну невідповідність у "Create Car" ("200" очікувався, "201" отримано) і залишив її як зафіксований FAIL.
